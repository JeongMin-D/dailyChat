# 제품 범위와 성공 기준

## 제품 한 문장

허용된 한 명의 사용자가 Telegram에서 나눈 일상 대화를 안전하게 보관하고, 그 근거만으로 검색 가능한 기록과 1인칭 일기를 만드는 개인용 비서다.

## 핵심 사용자 여정

1. 사용자가 Telegram으로 평소처럼 이야기한다.
2. 봇이 짧고 자연스럽게 답하고 원문을 저장한다.
3. 시스템이 하루 기록에서 사건·기분·건강·기억 후보를 추출한다.
4. 시스템이 근거가 연결된 일기 초안 또는 최종본을 만든다.
5. 사용자가 Telegram과 Web에서 확인하고 수정·삭제한다.
6. 이후 대화에서 확정된 장기 기억만 자연스럽게 활용한다.

## MVP In Scope

- Telegram 텍스트 대화와 단일 사용자 허용 목록
- Groq 호환 LLM 호출과 공급자 인터페이스
- 원문, 이벤트, 기분, 건강, 일기, 기억 데이터 저장
- KST 및 04:00 하루 경계 처리
- 야간 배치의 재시도와 재실행
- 일기 근거 보기
- 날짜별 일기·타임라인·키워드 검색
- 기억 조회·수정·비활성화·삭제
- 기본 피드백(좋아요/싫어요)
- RLS, 비밀 관리, 감사 로그, 백업·복구

## MVP Out of Scope

- 다중 사용자, 공개 가입, 결제
- 음성·사진·영상 분석
- 진단·처방·약물 의사결정
- 벡터 검색 및 추천 시스템
- 외부 서비스 자동 조작
- 완전 자동 모델 라우팅 최적화

## 성공 지표

| 영역 | MVP 합격 기준 |
|---|---|
| 수집 신뢰성 | 허용 사용자의 테스트 메시지 100개에서 유실 0, 중복 레코드 0 |
| 일기 근거성 | 표본 일기 문장 100%가 연결된 원문/이벤트로 설명 가능 |
| 추출 품질 | 골든셋 주요 이벤트 재현율 90% 이상, 잘못 만든 이벤트 5% 이하 |
| 안전 | 비허용 Telegram ID 차단, service role의 클라이언트 노출 0 |
| 운영 | 같은 날짜 배치를 재실행해도 중복 final이 생기지 않음 |
| 복구 | 문서화된 절차로 백업에서 복구 성공 |
| 사용성 | 날짜 선택 후 일기와 근거까지 3번 이하의 상호작용으로 도달 |

## 완료 정의

기능은 다음을 모두 만족해야 완료다.

- 구현 및 코드 리뷰 완료
- 정상·오류·재시도·권한 테스트 완료
- 로그와 운영 지표 추가
- 관련 Obsidian 문서와 결정 기록 갱신
- 비밀정보가 저장소와 브라우저 번들에 없음을 확인
- 사용자 시나리오 기준 수용 테스트 통과
