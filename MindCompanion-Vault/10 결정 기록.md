## ADR 작성 규칙

결정을 확정할 때 [[templates/ADR 템플릿]]을 복사하여 `decisions/ADR-NNN 제목.md`로 저장하고 이 표의 상태를 `승인`으로 변경한다. 결정이 바뀌면 기존 ADR을 삭제하지 않고 새 ADR에서 대체 관계를 남긴다.

## 즉시 권장하는 결정 조합

가장 단순하고 감사 가능한 MVP는 다음 조합이다.

- Groq provider 하나로 시작
- 04:05에 전날 final 생성
- Supabase를 모든 영속 데이터의 원장으로 사용
- Agent Memory 파일은 DB에서 재생성
- 추출과 일기는 한 번의 구조화 호출로 시작하되 저장 전에 엄격 검증
- Dashboard 검색은 날짜·키워드부터 제공
