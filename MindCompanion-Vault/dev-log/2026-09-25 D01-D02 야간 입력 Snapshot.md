# D01-D02 야간 입력 Snapshot

## 구현

- core time 모듈에 마지막으로 닫힌 local day 선택 함수 추가
- 공유 `nightlyInputSnapshotContract` 추가
- nightly Worker의 canonical snapshot/hash 생성기 추가
- Supabase user message day 조회와 1,000행 pagination 추가
- modern secret key와 legacy service role JWT header 처리
- 순서·hash 변화·빈 입력·잘못된 입력·API 오류 자동 테스트 추가

## 결정

- Scheduler가 target day를 선택하고 Worker 실행에는 명시적으로 전달한다.
- Snapshot version은 `1`이다.
- 포함 필드는 day와 user message의 id/sentAt/content로 제한한다.
- 정렬은 sentAt/id, 직렬화는 UTF-8 JSON, hash는 SHA-256 lowercase hex다.
- 원문 snapshot을 별도 테이블이나 job row에 저장하지 않는다.

## 실제 연결 검증

- 선택된 닫힌 날짜: 2026-09-24
- Data API snapshot user message 수: 5
- 같은 날짜의 DB 직접 count: 5
- snapshot version·hash 형식·정렬 정상
- 연속 두 번 조회한 snapshot과 hash 동일
- 검증 출력에 원문·비밀키·실제 hash를 포함하지 않음
