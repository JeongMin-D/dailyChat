# 개인정보 완전 삭제 RPC

## 구현

- 닫힌 local day의 파생 데이터와 원문을 한 트랜잭션에서 삭제하는 `delete_personal_data_for_day` RPC를 추가했다.
- 정확한 날짜 확인 문자열과 설정된 Telegram user/chat ID를 모두 요구한다.
- 열린 날짜, running job, sending 알림, 교차 날짜 근거는 자동 삭제하지 않는다.
- 기억 버전의 살아남은 후속 행은 삭제 대상 이전 버전 포인터만 해제한다.
- RPC는 invoker·빈 search path·service-role 전용으로 제한했다.

## 검증

- 운영 Supabase migration `personal_data_deletion` 적용
- 합성 원문·event·mood·health·diary·safety·memory·알림·job 삭제 후 전체 0건 확인
- 합성 검증 트랜잭션 rollback 후 잔존 0건 확인
- Data API에 잘못된 확인 문자열을 보내 안전한 400 응답 확인
- anon/authenticated 실행 불가, service role 실행 가능 확인
- `npm run check`: lint, typecheck, 자동 테스트 209개 통과
- 사용자 실제 데이터 삭제는 수행하지 않음
