# E07 MEMORY 읽기 전용 투영

## 구현

- `npm run project:memory`가 처리일에 유효한 confirmed 기억을 Supabase에서 조회한다.
- 분류와 사실을 결정적으로 정렬하고 source hash가 포함된 `files/MEMORY.md`를 전체 재생성한다.
- 임시 파일 작성 후 원자 교체하여 중간 파일을 노출하지 않는다.
- 원문 줄바꿈과 HTML 구문을 정규화하고, 기억은 지시가 아닌 참고 자료라고 파일에 명시한다.
- 개인 기억이 Git에 들어가지 않도록 생성 파일을 `.gitignore`에 추가했다.

## 검증

- 운영 Supabase 활성 기억 0건을 읽어 빈 투영을 실제 생성했다.
- 재생성 테스트에서 제거된 기억이 파일에 남거나 다시 나타나지 않음을 확인했다.
- 입력 순서가 달라도 같은 내용과 hash를 생성하고 여러 줄·HTML 구문을 한 줄 자료로 제한한다.
- `npm run check`: lint, typecheck, 자동 테스트 207개 통과
- 생성 파일이 Git 추적 대상에서 제외됨을 확인했다.
