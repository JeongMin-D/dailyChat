# D03-D04 구조화 추출과 검증

- 기준 커밋: `59e493a feat: build deterministic nightly input snapshot`
- `main`과 `origin/main` 동기화 상태 확인
- 기존 사용자 변경은 `MindCompanion-Vault/.obsidian/workspace.json` 한 건이며 수정·커밋 대상에서 제외

## 구현

- HTTP bounded retry를 `packages/core`로 이동하고 기존 bot은 re-export로 호환 유지
- `GroqNightlyExtractor`와 `nightly-v1` prompt 구현
- strict JSON Schema 요청, 빈 snapshot skip, refusal·HTTP·JSON 오류 분류
- snapshot day와 source ID, event 참조, 중복, safety 의미 검증
- 정제된 검증 경로만 사용하는 교정 1회 구현
- 합성 입력 기본 smoke와 명시적 `smoke:nightly:live-data` 분리

## 검증

- `npm run check`: lint, typecheck, 테스트 115개 통과
- `npm run smoke:nightly`: 실제 Groq 연결 성공
- 결과는 원문·일기 본문 없이 메타데이터만 출력
- 실제 사용자 원문 전송 smoke는 권한 검토에서 중단되어 실행되지 않음
- 저장소 diff에 `.env`와 비밀값이 포함되지 않도록 검사 예정
