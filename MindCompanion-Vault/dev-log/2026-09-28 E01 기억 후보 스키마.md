- Supabase 최신 changelog와 Data API·RLS 보안 지침을 확인했다. 신규 테이블 자동 노출 기본값에 의존하지 않고 권한을 명시했다.
- 공식 Supabase CLI로 `20260927160533_m3_memory_candidates.sql` migration을 생성했다.
- `memory_candidates`에 분류, 사실, 확신도, 확인 상태, 유효 기간과 job/day 참조를 추가했다.
- 원문과 event 근거는 `memory_candidate_message_sources`, `memory_candidate_event_sources` FK 관계로 분리했다.
- 운영 `dailyChat`에 migration을 적용하고 RLS 3개, service-role CRUD, anon/authenticated 차단을 확인했다.
- 정상 후보와 두 근거 저장, 잘못된 confidence·유효기간 거부를 운영 DB 트랜잭션에서 검증하고 전부 롤백했다. 후보 잔존은 0건이다.
