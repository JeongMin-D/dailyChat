# E06 기억 비활성화와 삭제

## 구현

- Telegram에서 `잊어줘` 또는 `/forget`을 보내면 활성 기억을 선택 버튼으로 표시한다.
- callback에는 후보 UUID만 넣고 설정된 Telegram user/chat ID를 DB에서 다시 검증한다.
- 선택한 confirmed 기억을 `forgotten`과 `forgotten_at`으로 논리 삭제한다.
- 같은 callback 재전달은 `noop`으로 처리하고, 비활성 기억은 대화 Context 조회에서 즉시 제외한다.
- 자연어 대상 추측과 물리 삭제는 오삭제·감사 손실을 막기 위해 사용하지 않는다.

## 검증

- `npm run check`: lint, typecheck, 자동 테스트 206개 통과
- 운영 Supabase migration `m3_memory_forget` 적용
- rollback 검증: 첫 호출 `updated`, 재호출 `noop`, 최종 `forgotten`
- 합성 job·기억 잔존 0건
- anon/authenticated RPC 실행 불가, service role만 실행 가능
- Render live에서 실제 `잊어줘` webhook `completed`, user/assistant 저장 각 1건 확인
- Telegram webhook pending 0건, 최근 오류 없음 확인
