# M2 종단 실행기

## 작업 전 확인

- 기준 커밋: `e7fae58 feat: route urgent diary notifications safely`
- 기존 사용자 변경: `.obsidian/workspace.json`
- 기능·설정과 충돌하지 않아 보존하고 작업 범위에서 제외했다.

## 구현

- `NightlyPipelineRunner`로 input→prepare→claim→extract→save→enqueue→deliver를 조합했다.
- `SupabaseNightlyOutputStore.claimRun()`으로 기존 `claim_job_run` RPC를 Worker에 연결했다.
- 빈 입력, 성공 no-op, 동시 실행 claim 패배, terminal 실패, stale running 재개를 명시적으로 처리했다.
- `npm run run:nightly` CLI와 pipeline version·수동 target day 환경값을 추가했다.
- 실행 로그는 day, 상태, 식별자, attempt만 사용하고 원문과 일기 본문을 포함하지 않는다.

## 검증

- 신규 종단 경로와 예외 분기 단위 테스트를 추가했다.
- 실제 Supabase Data API에서 존재하지 않는 job UUID를 claim해 `false` 응답을 확인했다.
- 운영 데이터를 만들거나 변경하지 않았고 실제 Groq·Telegram 호출도 하지 않았다.
- `npm run check`: lint, typecheck, 자동 테스트 161개 통과.
