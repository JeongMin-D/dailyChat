# 삭제 재등장 방지와 Dashboard 읽기 완성

## 완료

- 날짜·허용 Telegram 사용자·확인 문자열을 DB 완전 삭제 RPC에 전달하는 운영 CLI를 추가했다.
- 삭제 직후 활성 기억으로 `MEMORY.md`를 다시 만들어 삭제 원문이 투영에 남지 않게 했다.
- 가짜 저장소 회귀 테스트에서 삭제 대상 문구는 사라지고 다른 날짜 기억은 유지됨을 검증했다.
- Dashboard에 표준 날짜 계산 기반 월간 Calendar와 일기 블록별 원문 메시지 이동 링크를 추가했다.

## 검증

- `npm run check`: lint, typecheck, 자동 테스트 211개 통과
- 비밀값과 실제 사용자 원문은 코드·테스트·문서에 추가하지 않았다.

## 다음

- 일기 피드백과 기억 관리 화면을 구현한다.
- 무료 요금제에 맞는 외부 백업과 복구 리허설 방법을 확정한다.
