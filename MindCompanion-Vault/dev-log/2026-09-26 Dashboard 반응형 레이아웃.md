# Dashboard 반응형 레이아웃

## 구현

- Sidebar 폭, 본문 여백, 제목과 카드 padding을 `clamp()` 기반 유동 크기로 전환했다.
- 1180px 이하에서 타임라인과 wellbeing 영역을 세로로 분리하고 기분·건강 카드를 2열로 배치한다.
- 900px 이하에서 Sidebar를 상단 헤더로 바꾸고 최근 기록을 가로 스크롤 목록으로 전환한다.
- 650px 이하에서 상단 도구와 wellbeing 카드를 1열로 배치하고 일기 태그를 제목 아래로 이동한다.
- 360px 이하에서 통계와 입력 도구를 1열로 전환한다.
- 통계 카드는 `auto-fit`과 최소 폭으로 화면에 맞춰 열 수가 자동으로 바뀐다.

## 디자인 결함 수정

- 해시태그에 `inline-flex`, 고정 shrink, 내부 줄바꿈 방지를 적용했다.
- 타임라인 개수 배지를 전용 class로 분리해 제목 높이만큼 늘어나지 않게 했다.
- 시간은 24시간제로 표시해 좁은 열에서 오전·오후가 별도 줄로 갈라지지 않게 했다.
- CSP가 차단하던 기분 막대 인라인 높이를 점수별 CSS class로 교체했다.
- 기분 날짜를 가로 표기로 바꾸고 데이터가 많을 때 차트 내부만 스크롤하도록 했다.
- 긴 대화와 일기 문장은 카드 내부에서 안전하게 줄바꿈한다.
- 링크, 버튼, 입력에 키보드 focus 표시를 추가했다.

## 검증

- 1278px: Sidebar·본문 2단, 타임라인·wellbeing 2단, 문서 가로 넘침 없음.
- 768px: 상단형 탐색, 통계 4열, 기분·건강 2열, 문서 가로 넘침 없음.
- 390px: 통계 2열, 단일 본문 흐름, 해시태그 높이 26px, 개수 배지 높이 26px, 문서 가로 넘침 없음.
- 기분 점수 3 막대가 68px로 렌더링되어 기존 0px 결함이 해소됐다.
- `npm run check`: lint, typecheck, 자동 테스트 175개 통과.
