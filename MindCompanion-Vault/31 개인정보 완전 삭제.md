# 개인정보 완전 삭제

## 범위

MVP는 닫힌 local day 하나를 완전 삭제하는 서버 전용 경로를 제공한다. 열린 오늘은 Telegram 수신과 충돌할 수 있으므로 다음 04:00 경계가 지난 뒤 삭제한다.

## 사전 조건

1. 사용자가 삭제 날짜를 명시적으로 확인한다.
2. 서버가 설정된 Telegram user ID와 chat ID를 함께 전달한다.
3. 해당 날짜에 running job 또는 sending 알림이 없어야 한다.
4. 원문과 다른 날짜 파생 자료의 교차 근거가 없어야 한다.

## 트랜잭션 순서

```text
memory/diary notification outbox
 → memory candidates와 근거
 → safety assessments
 → diaries와 blocks
 → health / mood / events
 → messages
 → telegram_updates
 → job_runs
```

어느 단계든 FK·권한·상태 검증이 실패하면 전체 트랜잭션을 rollback한다. 결과에는 삭제 건수만 반환하고 원문이나 파생 본문을 포함하지 않는다.

## 보안 경계

- RPC: `delete_personal_data_for_day(date, text, bigint, bigint)`
- `SECURITY INVOKER`, 빈 `search_path`
- `anon`·`authenticated` 실행 불가, `service_role`만 실행
- Dashboard 또는 Telegram UI에는 아직 직접 노출하지 않는다.

## 후속 처리

- 성공 직후 `MEMORY.md`를 다시 생성한다.
- 애플리케이션 캐시가 추가되면 같은 삭제 완료 이벤트로 무효화한다.
- 삭제 전 자체 백업을 폐기하고 삭제 후 새 기준 백업을 생성한다.

결정 근거는 [[decisions/ADR-010 원문과 파생 데이터 완전 삭제]], 보존 상한은 [[decisions/ADR-012 개인정보 보존 기간]]을 따른다.
