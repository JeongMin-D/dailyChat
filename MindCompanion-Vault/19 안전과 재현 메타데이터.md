# 안전과 재현 메타데이터

## 목적

C05는 야간 생성 결과를 어떤 입력·모델·프롬프트·schema로 만들었는지 재현하고, safety 분기에 필요한 최소 메타데이터만 보존한다. 실행 계약은 `packages/contracts/src/job-contract.js`, DB 구현은 `database/migrations/0006_safety_reproducibility.sql`이다.

## Nightly 실행 재현 정보

`job_type=nightly`인 run은 다음 값을 모두 가져야 한다.

| 필드 | 규칙 |
|---|---|
| `day` | 명시적인 처리 대상 local day |
| `pipeline_version` | 저장·검증 파이프라인 버전 |
| `input_hash` | canonical input snapshot의 lowercase SHA-256 hex 64자 |
| `provider` | MVP는 `groq` |
| `model` | 실제 요청한 모델 ID |
| `prompt_version` | 검증된 야간 프롬프트 버전 |
| `schema_version` | Structured Output 계약 버전, 현재 `1.0.0` |

비밀키, 입력 원문, 모델 응답 본문은 job run에 저장하지 않는다. canonical snapshot과 hash 생성은 [[21 야간 입력 Snapshot]]에 구현했으며 같은 day·pipeline version·input hash 조합은 기존 unique 멱등 키를 사용한다.

## Safety 저장 범위

모델 출력의 `none|concern|urgent` 중 DB에는 `concern|urgent`만 저장한다.

저장 필드:

- run ID와 local day
- level
- 허용 사유 코드 `self_harm|suicide|acute_distress`
- checker version
- 판정 시각
- 검증된 source message FK

저장하지 않는 정보:

- 원문 인용이나 대화 본문
- 진단명·처방·의학적 결론
- 자유 형식 모델 추론·설명
- 일기나 건강 기록 본문

`safety_assessments`는 한 run당 최대 한 행이고 reason code는 1~3개다. source 관계는 `safety_message_sources` 복합 PK로 저장한다. source snapshot 소속, code 중복과 최소 근거는 Worker가 저장 전 검증하고 한 트랜잭션으로 넣는다.

## 삭제 정책과 접근 통제

- safety → source 연결: parent 삭제 시 cascade
- source message: safety가 남아 있으면 restrict
- safety → job run: job run 삭제 restrict
- safety 두 테이블 모두 RLS 활성화
- `anon`, `authenticated` CRUD 없음
- server-only `service_role` CRUD만 허용
- Dashboard 소유자 정책은 G01 전까지 없음

## 실DB 검증

- 완전한 nightly 재현 필드 저장 성공
- 누락된 재현 필드와 대문자·길이 오류 hash 거부
- safety none, 미허용 사유, 빈 사유 거부
- 한 run의 중복 assessment와 중복 source 거부
- safety가 참조하는 원문 삭제 거부
- 민감 자유 형식 컬럼 부재 확인
- 임시 검증 데이터 rollback 및 잔여 0건

## D10 발송 분기

| 안전 등급 | Outbox 유형 | 사용자에게 보내는 내용 |
|---|---|---|
| `none` | `daily_diary` | 일반 일기 |
| `concern` | `daily_diary` | 고정 지지 문구 + 안전하게 생성된 일기 |
| `urgent` | `safety_guidance` | 일기 본문 없이 검증된 고정 안전 안내 |

urgent payload에는 등급·날짜·수신 chat ID 같은 라우팅 정보만 있고 diary title, block, reason code, source 원문이 없다. 안전 안내는 진단이나 자동 신고를 하지 않으며 즉시 위험 시 112/119, 24시간 자살예방 상담전화 109와 정신건강 위기상담전화 1577-0199를 안내한다.
