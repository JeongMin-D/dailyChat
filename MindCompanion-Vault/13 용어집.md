# 용어집

| 용어 | 의미 |
|---|---|
| local day | KST 04:00부터 다음 날 03:59:59까지의 기록 날짜 |
| 원문 | 사용자가 보내거나 assistant가 보낸 변경 전 메시지 |
| 이벤트 | 원문에서 확인된 의미 있는 사건의 구조화 표현 |
| 근거 | 파생 데이터가 참조하는 원문 또는 확정 이벤트 |
| 기억 후보 | 장기 사용 가치가 있으나 아직 확정되지 않은 사실 |
| 활성 기억 | 대화 컨텍스트에 사용할 수 있는 확정 기억 |
| 기억 원장 | 근거, 상태, 이력을 가진 장기 기억의 영속 저장소 |
| 투영 | 원장에서 생성한 `MEMORY.md` 같은 읽기 최적화 복사본 |
| draft 일기 | 하루가 닫히기 전에 만든 변경 가능한 일기 |
| final 일기 | 하루 경계 이후 고정된 입력으로 만든 최종 버전 |
| input hash | 야간 작업 입력이 같은지 판단하는 해시 |
| 골든셋 | 기대 결과를 사람이 검토해 고정한 평가용 대화 모음 |
| RLS | 데이터베이스 행 단위 접근 제어 |
| outbox | 생성과 외부 발송을 분리하여 안정적으로 재시도하는 작업 저장소 |
