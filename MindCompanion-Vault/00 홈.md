## 진행 현황

| 마일스톤 | 상태 | 종료 조건 |
|---|---|---|
| M0 설계 확정 | 진행 중 | P0 결정·C01~C06 완료, rollback·골든셋·설계 리뷰 남음 |
| M1 대화 수직 슬라이스 | 완료 | 실제 대화·저장·배포·재시도·DB 장애·보안 종료 검토 통과 |
| M2 야간 기록 파이프라인 | 진행 중 | 추출·검증 완료, 저장·근거 연결·전송 남음 |
| M3 장기 기억 | 대기 | 기억 생성·활용·수정·삭제 성공 |
| M4 읽기 전용 대시보드 | 대기 | 날짜별 일기·타임라인·검색 가능 |
| M5 안정화와 배포 | 진행 중(선행) | Render 배포·기본 관측성 완료, 백업·복구 미완료 |

상태 값은 `대기 → 진행 중 → 검증 중 → 완료` 순서로 갱신한다.

## 핵심 원칙

- 원문 메시지는 변경하지 않는 근거 데이터다.
- 구조화 데이터와 일기는 반드시 원문 근거를 추적할 수 있어야 한다.
- 추정과 사용자 진술을 구분하고, 불확실성을 저장한다.
- 사용자는 자신의 기억과 일기를 조회·수정·삭제할 수 있어야 한다.
- 의료 진단이나 감정 단정은 하지 않는다.
- MVP는 단일 사용자, 텍스트, 읽기 중심 대시보드로 제한한다.
